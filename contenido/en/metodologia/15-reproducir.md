## How to reproduce and cite

```
pip install -r requirements.txt
python run.py                 # downloads, computes and writes resultados/ and site/data/
```

Modules:

- `sismografo/descarga.py`: sources.
- `eeuu.py`: multiverse, surplus value and labour time.
- `trimestral.py`: quarterly estimate.
- `mundo.py`: PWT.
- `ocde_ramas.py`: measurement by industry with the OECD accounts.
- `horas_mundo.py`: world mass in hours (WIOD, OECD, ILO; net version; sensitivity).
- `ia.py`: AI corporations.
- `quiebres.py`: break detector.
- `sitio.py`: site JSON.
